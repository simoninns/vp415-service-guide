# Repair method

Chapter 6 is the part of the manual you use first. The VP415 diagnoses itself:
the diagnostic software built into the drive processor watches the drive's own
tasks and puts an error code on the picture when one fails. Chapter 6 tells you
how to make it do that, what the codes mean, and how to get from a code to a
module.

## The manual's own contents

The chapter is titled *Repair Method* and published by Service Consumer
Electronics for the **LaserVision ROM disc drive VP415/00/05/35**. Its contents
page lists:

1. Introduction
2. Diagnostic software
    - a. Set-up
    - b. Switching on the diagnostic software — 1. check mode, 2. self-test mode
    - c. Reproducing the error codes on the screen — 1. check mode, 2. self-test mode
    - d. Programme loop in the self-test mode
    - e. Meaning of the error codes
3. Fault-finding
    - a. Meaning of the symbols used
    - b. Test procedure

Items 1 and 2 are on [diagnostic mode](diagnostic-mode.md), except 2e which has
a page of its own at [error codes](error-codes.md); item 3 is on
[fault-finding charts](fault-finding.md).
