# List of mechanical parts

Applies to **22VP415/00/05/35**. Where the /00, /05 and /35 versions differ,
the item is listed once per version — see item 301 (ornamental plate) and item
368 (mains cord).

The item numbers key into the [exploded views](exploded-views.md): find the
part on the drawing, read its number, look it up here.
