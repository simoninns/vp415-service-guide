# Operating instructions

**This is the user manual, not the service manual.** Philips published two
books for the VP415: the service manual the rest of this site is built from,
and this one — 45 pages telling an owner how to install the player, play a
disc, and drive it from a computer. It is kept as its own section so the two
are never confused.

It is worth reading even if you only ever service the machine. The service
manual assumes you already know what the front panel does, what an F-code is,
and what the SCSI interface is for; this book is where that is written down.

## About this transcription

Every page of the printed book is here, transcribed from the vendor OCR and
corrected against the photographs, with the scan of each page beside the text
it came from. The manual's own numbering is kept: where a page says *see
Section 6*, the link goes to [F-code commands](f-code-commands.md), which is
section 6.

Two tables from section 5 — the F-code command list and the acknowledgements —
are reproduced on the [F-code reference](../reference/f-codes.md) rather than
twice, because that page also carries what a real player answers, which the
manual never had.
