# Service tools

Two sheets: what is in the Philips service kit, with code numbers, and
photographs of each piece in use inside the player.

## Test discs and screwdrivers

| Item | Service code number |
| --- | --- |
| Test disc 6" | 4822 397 30156 |
| Test disc 8" | 4822 397 30118 |
| Test disc 12" | 4822 397 30119 |
| Torx screwdriver set | 4822 395 50145 |

The 6" test disc is the one to use with the player on its side, and it may only
be played with the front loader removed — see [warnings](warnings.md).

| 1 | Disc clamping piece | — | 4822 532 60775 |
| 1 | Frontloader simulation — **pins 3 and 4 interconnected** | — | 4822 267 50706 |

Two pieces in that list are just modified connector shells, and both are
straightforward to make:

- the **frontloader simulation** plug is a 6-way housing with pins 3 and 4
  shorted, which tells the drive processor the loader is closed so the deck will
  run with the front loader removed;
- the **VID MIX coupling piece** has pins 1 to 4 removed, which short-circuits
  the video-mixer signals — VP415 only.

The [RGB module calibration guide](../reference/calibration/rgb-module.md)
describes making both, and an extender cable, from modern parts.

## Application of the service tools

The second sheet photographs six set-ups:

| Set-up | Tools used |
| --- | --- |
| 6" test disc on the deck | Test disc 6", disc clamping piece |
| Extension of a module (flex) | Ext. assy 6P, ext. assy 10P |
| Extension of a module (steady) | Ext. assy 6P, ext. assy 10P |
| Extension of the motor module | Coupling piece 12P, ext. cable 12P, ext. assy 12P, ext. assy 6P |
| Extension of the drive / control module | 2 × extender print 64P, front loader simulation |
| Short-circuiting the VID MIX signals — VP415 only | Coupling piece VID MIX |

"Flex" and "steady" are the two ways of extending a plug-in module: hanging it
on the extension assemblies clear of the cage, or resting it on the cage edge
where it will not move while you probe.
