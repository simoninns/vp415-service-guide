# Controls, indicators and connections

The front panel carries the eject and standby buttons and a row of status
indicators; everything else is on the rear. The numbers below are the manual's
own, and they are used throughout the site whenever a rear-panel connector is
named.

## Front

The EJECT button sits at the left, with the ON/STANDBY button below it; the
indicators run left to right across the panel.

- EJECT button
- STANDBY indicator
- ON/STANDBY button
- EJECT indicator
- PAUSE indicator
- REPLAY indicator
- REPEAT indicator
- AUDIO 1 indicator
- AUDIO 2 indicator
- CAV indicator
- CLV indicator
- REMOTE CONTROL indicator

## Rear

| No. | Connection |
| --- | --- |
| 1 | ON/OFF switch |
| 2 | MAINS lead socket |
| 3 | REPLAY on/off switch |
| 4 | RC IR/EURO switch |
| 5 | WIRED RC socket |
| 6 | RS232C socket |
| 7 | BAUD RATE dip switches |
| 8 | AUDIO IN (1 & 2) sockets |
| 9 | AUDIO OUT (1 & 2) sockets |
| 10 | A/V EUROCONNECTOR |
| 11 | H-SHIFT control (for genlock) |
| 12 | CVBS OUT socket |
| 13 | SYNC OUT socket |
| 14 | CVBS IN socket |
| 15 | SYNC IN sockets |
| 16 | RGB (TTL) IN socket |
| 17 | SCSI address dip switches |
| 18 | SCSI socket |

The pin assignments for 6, 10, 16 and 18 are on the
[connector pinning](connector-pinning.md) page, together with the baud-rate
settings for switch bank 7.

!!! note "Mains voltage on the type plate"

    The manual's technical data gives the mains range as 220–240 V, and the
    line drawing labels the inlet `100-240V~`. The type plate on the player
    photographed above reads 240 V, 0.4 A, 70 W. Read the plate on the player
    in front of you before you connect it.

## Remote control functions

- Play forward/reverse
- Still frame / step forward/reverse
- Audio 1/2 on/off
- Picture number / time display on/off
- Chapter number display on/off
- Programme display on/off
- Search forward/reverse (20 × normal speed)
- Goto (picture or chapter number)
- Input correction
- Digits 0–9 entry
- Fast forward/reverse (3, 10, 20 × normal speed)
- Slow forward/reverse (1/100 to normal speed)
- Fast/slow rate +/−
- Clear memory
- Enter
- Standby
- Pause
- Start/Repeat
- Next

The handset itself, its exploded view and the RC5 receiver it talks to are
covered on the [remote control](../modules/remote-control/index.md) page.
